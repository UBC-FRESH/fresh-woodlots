# Document library

A local, searchable copy of the relevant BC government woodlot documents is at:

```text
data/library/woodlot/
```

The library is generated by:

```bash
python scripts/build_doc_library.py
```

## What it contains

| Category | Contents |
|---|---|
| `raw/aac-tool/` | Woodlot for Windows 4.4 MSI, What’s New, User Guide, nine training videos |
| `raw/woodlot-planning/` | Management Plan Handbook, management-plan template, inventory handbook, WLP guidance/templates |
| `raw/policy/` | Woodlot policy 8.7–8.10, private-land policy, old-growth bulletin |
| `raw/cut-control/` | Cut-control guidance |
| `raw/transfers/` | Disposition guide and RAIT template |
| `raw/first-nations/` | Consultation and information-sharing documents |
| `raw/legislation/` | Forest Act, Woodlot Licence Regulation, Cut Control Regulation, FRPA, WLPPR, and related Acts |
| `raw/woodlot-specific/W0026/` | W0026 WLP, WLP extension, cut-control statement, AAC dossier |
| `text/` | Extracted text for search (PDFs, DOC/DOCX, XLS/XLSX, HTML) |
| `pages/` | Source HTML and text for the two BC government pages |
| `INDEX.md` | Human-readable index with source URLs (also published at `library/woodlot-INDEX`) |
| `index.json` | Machine-readable manifest: URL, path, SHA256, MIME type, extraction status |

## Search

```bash
python scripts/search_doc_library.py --query "allowable annual cut"
python scripts/search_doc_library.py --query "pthlb" --context 2
python scripts/search_doc_library.py --query "schedule A" --category woodlot-planning
rg -n -i "allowable annual cut" data/library/woodlot/text
```

## Provenance and licensing

Documents are publicly linked from:

- <https://www2.gov.bc.ca/gov/content/industry/forestry/forest-tenures/timber-harvesting-rights/woodlot-licence>
- <https://www2.gov.bc.ca/gov/content/industry/forestry/forest-tenures/timber-harvesting-rights/woodlot-licence/allowable-annual-cut-calculator-tool>
- the W0026 district/archived records collected in `docs/aac/W0026-AAC-DOSSIER.md`

BC government documents are generally under the Open Government Licence –
British Columbia. The Woodlot for Windows installer and training videos are
provided by the Province at no charge; keep the local copy for analysis and do
not redistribute the software or media without checking the applicable terms.
See `data/library/woodlot/LICENSE-NOTES.md`.

## Coverage notes

At build time the library contained **59 records** and **one broken source
link** (the “Cutting Permit Extension and Surrender” asset download). The
broken link is recorded in `index.json` under `failed`. Five PDFs are scanned
or image-heavy and produced little/no extracted text; they are still stored
and searchable by title/metadata. Ten records are non-text (MSI + nine WMV
training videos).
