# FHOPS selected-area audit

The first-period FHOPS pilots compress ten years of AAC into a short horizon. Volume per selected scheduled hectare is a screening check, not a yield-table validation.

- Instances audited: **798**
- Median volume / selected ha: **450.1 m³/ha**
- 90th percentile: **980.9 m³/ha**
- Check (> 1,000 m³/ha): **70**
- Extreme (> 5,000 m³/ha): **5**
- Missing/zero selected area: **0**

## Interpretation

A high value normally means the compressed pilot selected too little block area for the volume assigned to it. It is not evidence that the woodlot has that yield. Featured tactical plans now draw from all compiled WS4 blocks and generally sit near 90–120 m³/ha for the ten-year volume.

The portal labels `check`, `extreme`, and `missing` cases as **⚠ area check**. The label is a prompt to inspect the block selection, not a conclusion about the woodlot.
